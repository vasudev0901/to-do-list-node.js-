# 📝 Node.js To-Do List

A simple **To-Do List** application built using **Node.js, Express, EJS, HTML, and CSS**. Users can add tasks and remove tasks from the list.

---

## 🚀 Features

- ➕ Add a new task
- 🗑️ Delete a task
- 📋 Display all tasks
- 🎨 Simple and responsive UI
- ⚡ Built using Express and EJS
- 📌 Uses `GET`, `listen`, `map`, `req`, and `res`

---

## 🛠️ Technologies Used

- Node.js
- Express.js
- EJS
- HTML5
- CSS3
- JavaScript

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/todo-list.git
```

2. Go to the project folder

```bash
cd todo-list
```

3. Install dependencies

```bash
npm install
```

4. Start the server

```bash
node app.js
```

5. Open your browser

```
http://localhost:3000
```

## 📷 Application Preview

- Enter a task name.
